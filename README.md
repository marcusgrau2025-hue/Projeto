# Sistema de Biblioteca

Sistema web para controle de livros, alunos e empréstimos, feito em Python com Flask e programação orientada a objetos.

## Funcionalidades
- Cadastro, busca e exclusão de livros
- Cadastro e exclusão de alunos
- Registro de empréstimos e devoluções com prazo de 7 dias
- Destaque de empréstimos atrasados

## Como executar
1. git clone https://github.com/marcusgrau2025-hue/Projeto.git
2. cd Projeto
3. python3 -m venv venv
4. source venv/bin/activate
5. pip install -r requirements.txt
6. python app.py
7. Abra http://127.0.0.1:5000 no navegador
